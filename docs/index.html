Canary CLI

The open-source foundation of Desk. Connect to Interactive Brokers, inspect portfolio and market evidence, and give AI agents read-only tools for analysis.

View on GitHub ↗ Install ↓

MCP tools are read-only. Standard downloads have no order entry. Trading actions require a separate opt-in build, authority checks and owner confirmation.

Read from your local broker session 
$ canary brief
$ canary positions
$ canary rules

Portfolio review

Holdings, exposure, risk checks and broker-statement reconciliation, with source and freshness information.

For agents

Read-only MCP tools connect your broker evidence to Claude and other AI assistants.

03

Native Go

The Go library speaks the IBKR TWS protocol directly. No Python bridge or vendor SDK.

Get started

Install Canary

IB Gateway 10.37+ or TWS must run locally. Requires an IBKR Pro account with TWS API access; IBKR Lite does not include it.

Claude Desktop install ↗
Claude Code or the command line 
# Claude Code plugin
/plugin marketplace add osauer/canary
/plugin install canary@canary
# restart Claude Code or run /reload-plugins after install/update

# Shell, Cursor, Continue, Zed, generic MCP hosts
curl -fsSL https://raw.githubusercontent.com/osauer/canary/main/install.sh | sh
canary setup claude-desktop

# then ask:
# "How does my IBKR account look today?"
