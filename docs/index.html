Canary CLI

A local risk desk for your broker account. It checks your book against your risk rules and drafts the protection they call for.

View on GitHub↗ Install↓

The open-source engine under Canary Desk. It runs with Interactive Brokers today, through IB Gateway or TWS; the broker layer is its own Go package.

01

Your book, with its evidence

Positions, exposure and reconciliation against broker statements. Stale or missing data stays labelled, never filled in.

02

Rules that draft protection

A rulebook checks the book every minute. When a rule trips, Canary drafts the stop, exit or budget cut it calls for.

03

Orders within your limits

The trading build sends what you confirm, and what you have pre-authorised by rule. Every order passes Canary’s checks.

04

For AI assistants

MCP tools give Claude and other assistants the same evidence to reason over. The TWS protocol is spoken natively in Go, with no vendor SDK.

Full features

What’s inside.

Market context

  • Market regimeEight readings in six groups, from volatility and credit to dealer gamma and breadth, read into one regime stage.
  • BreadthS&P 500 names above their 50- and 200-day averages, computed from constituent prices.
  • Stress signalAn early warning when the regime turns.
  • CalendarMarket sessions, holidays and events ahead.

Your book

  • Positions and exposureStocks, options and bonds, with sector allocation.
  • PerformanceA statement-based return series, net of cash flows.
  • EdgeWhat your trades delivered compared with leaving the position alone.
  • ReconciliationFigures checked against broker statements. Gaps stay visible.

Rules and protection

  • Risk rulebookYour limits, checked every minute.
  • Protection proposalsStops, exits, trims and budget cuts, each with its reason.
  • Cash sweepIdle cash into short-dated government bills, and back.
  • Trading buildSends what you confirm or pre-authorise, through Canary’s checks.

Where you use it

  • Command lineOne binary for macOS and Linux.
  • AI assistantsMCP tools for Claude and other hosts.
  • Your phoneA paired app with live updates and opt-in notifications.
  • Go libraryThe TWS protocol, spoken natively in Go.

Get started

Install Canary

Run IB Gateway 10.37+ or TWS on the same machine. You need an IBKR Pro account with TWS API access; IBKR Lite does not include it.

Claude Desktop install↗
Claude Code or the command line 
# Claude Code plugin
/plugin marketplace add osauer/canary
/plugin install canary@canary
# restart Claude Code or run /reload-plugins after install/update

# Shell, Cursor, Continue, Zed, generic MCP hosts
curl -fsSL https://raw.githubusercontent.com/osauer/canary/main/install.sh | sh
canary setup claude-desktop

# then ask:
# "How does my IBKR account look today?"
